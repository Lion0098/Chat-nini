# Chat Nini / چت‌نینی

پیام‌رسان وب، فارسی و راست‌به‌چپ، با چت خصوصی و گروهی، وضعیت، تماس مرورگری و پنل مدیریت.

ریپازیتوری: [Lion0098/Chat-nini](https://github.com/Lion0098/Chat-nini)

گیت‌هاب فاصله را در نام مخزن قبول نمی‌کند؛ نام مخزن `Chat-nini` است (همان Chat nini).

## چه چیزی لازم ندارد

- سرور دائمی یا VPS لازم نیست. درخواست‌ها کوتاه‌اند و تازه‌سازی گفتگو با polling انجام می‌شود.
- فایل‌ها داخل Postgres ذخیره می‌شوند، نه روی دیسک.
- تماس صوتی/تصویری WebRTC است: سیگنال از خود برنامه رد می‌شود و رسانه مستقیم بین دو مرورگر می‌رود. بعضی شبکه‌ها بدون TURN وصل نمی‌شوند.

## اجرا

```bash
npm install
npm run dev
```

ورود با ایمیل و رمز، یا گوگل و ایکس. شماره تلفن برای ورود لازم نیست؛ نام کاربری یکتا است و شماره را می‌توان در نمایه گذاشت تا بقیه پیدایت کنند.

اولین حسابی که وارد شود مدیر است و از منو به پنل مدیریت می‌رود.
